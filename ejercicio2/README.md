# Ejercicio 2 - API REST de Noticias (NewsAPI)

## Como ejecutar

1. Instalar dependencias:
   npm install

2. Crear un archivo .env en esta carpeta (basado en .env.example)
   con tu propia apiKey de https://newsapi.org:

   NEWS_API_KEY=tu_api_key
   PORT=3000

3. Iniciar el servidor:
   npm start

4. Abrir en el navegador: http://localhost:3000
5. Probar en Postman: GET http://localhost:3000/api/noticias
